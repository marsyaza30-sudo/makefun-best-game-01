Prism Drift — an original arcade-puzzle browser game. Glowing orbs rain down in facet colours and shapes; slide the prism catcher and rotate its active facet to match each orb, build combos, restore the Core to 1,000 points before your three lives run out. Pure HTML/CSS/JavaScript on canvas with synthesized WebAudio sound — no build step, no network, fully deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
